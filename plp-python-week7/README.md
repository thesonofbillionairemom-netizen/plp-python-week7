
# Week 7 Assignment: My Notes & The Report Builder

**Author:** Abdiwali(Amiir) Abdi
## Project Overview

This project demonstrates Python file handling, CSV data processing, exception handling, and automated report generation.

It consists of two Python programs that demonstrate practical applications of reading, writing, appending, and processing files.

## Project Structure

| File | Description |
|---|---|
| my_notes.py | Writes, appends, reads, and counts notes in a text file. |
| my_notes.txt | Stores the four notes generated by my_notes.py. |
| report_builder.py | Reads learner records from a CSV file and generates a report. |
| hubs.csv | Contains learner names, hubs, and assessment scores. |
| report.txt | Stores the generated learner performance report. |
| README.md | Provides project documentation and usage instructions. |

## Question 1: My Notes

The my_notes.py program demonstrates Python file handling using three file modes:

- Write mode (`w`) creates a file or overwrites existing content.
- Append mode (`a`) adds new content without deleting existing information.
- Read mode (`r`) retrieves and displays stored information.

The program writes three notes, appends a fourth note, displays all four notes, and counts the total number of lines.

### Expected Output

    --- My notes ---
    Python is fun
    Files are useful
    Week 7 is going well
    I added this later
    Total lines: 4

## Question 2: The Report Builder

The report_builder.py program uses Python's csv module to read learner information from hubs.csv.

It processes learner scores, counts passing learners, calculates the number of failures, and generates report.txt.

### Expected Report

    LEARNER REPORT
    Total learners: 5
    Passed: 3
    Failed: 2
    Average score: 63.2

## Error Handling

The Report Builder uses FileNotFoundError to handle a missing CSV file without crashing.

If hubs.csv is unavailable, the program displays an appropriate message and continues safely.

## Understanding Append Mode

If I changed "a" to "w" in Question 1, the program would overwrite the existing contents of my_notes.txt instead of adding the fourth note. The first three notes would be erased, leaving only the newly written content.

## How to Run the Programs

Run the My Notes program:

    py my_notes.py

Run the Report Builder:

    py report_builder.py
